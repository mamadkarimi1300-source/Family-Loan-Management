# Family Loan Management

سامانه ساده مدیریت وام خانوادگی با رابط تلگرام.

## ساختار پروژه

- `app/bot/`: دریافت پیام‌ها و نمایش منوهای ربات تلگرام.
  - `handlers/`: پردازش فرمان‌ها و پیام‌های کاربران.
  - `keyboards/`: تعریف دکمه‌ها و صفحه‌کلیدهای ربات.
- `app/users/`: ثبت و مدیریت اعضا و اطلاعات اشخاص.
- `app/loans/`: ثبت و پیگیری وام‌ها، مبلغ، تاریخ و وضعیت هر وام.
- `app/payments/`: ثبت پرداخت‌ها و پیگیری اقساط.
- `app/reports/`: تهیه گزارش از وام‌ها، پرداخت‌ها و مانده بدهی.
- `database/`: مدل داده‌ها و ارتباط با پایگاه داده.
- `config/`: تنظیمات برنامه، مانند توکن ربات و مشخصات اتصال پایگاه داده.
- `tests/`: آزمون بخش‌های مختلف برنامه.
- `main.py`: نقطه شروع اجرای برنامه.
- `requirements.txt`: فهرست کتابخانه‌های موردنیاز پایتون.
- `.env.example`: نمونه متغیرهای محیطی؛ مقادیر محرمانه واقعی را در این فایل قرار ندهید.
- `.gitignore`: مشخص می‌کند چه فایل‌هایی وارد Git نشوند.

## مسیر کلی یک درخواست

کاربر در تلگرام پیام می‌دهد ← بخش ربات پیام را دریافت می‌کند ← Handler درخواست را به ماژول مرتبط می‌فرستد ← ماژول با پایگاه داده کار می‌کند ← نتیجه به کاربر نمایش داده می‌شود.

> این مخزن فعلاً فقط اسکلت و مستندات اولیه پروژه را دارد؛ منطق برنامه هنوز پیاده‌سازی نشده است.
